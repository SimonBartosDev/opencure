# Cystic fibrosis — outreach brief

> **Disease class:** `chronic_systemic` &nbsp; | &nbsp; **Lead disease:** no

## Why this disease

CFTR mutations. Trikafta covers ~90 % of patients; minor-allele patients still unmet.

3. **Testosterone**  (p = 0.83)
4. **Hydrocortisone**  (p = 1.00) — Prednisolone

- **Readout:** Forskolin-induced swelling at 1 h
