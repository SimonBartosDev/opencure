# Hepatitis C — outreach brief

> **Disease class:** `viral` &nbsp; | &nbsp; **Lead disease:** no

## Why this disease

HCV genotype 1-6. DAAs curative for most patients; remaining unmet need is access and resistance-associated substitutions.

## Top OpenCure predictions (v7)

1. **Clobetasol propionate**  (p = 0.01)
2. **Mitoxantrone**  (p = 0.06)
3. **Tacrolimus**  (p = 0.03)
4. **Amprenavir**  (p = 0.30)
5. **Alosetron**  (p = 0.00)

Per-candidate mechanism, conformal interval, red-team critique, and
suggested-assay details are in
`experiments/results/briefs/Hepatitis_C_top5.md`.

## Suggested assay

- **Assay:** Replicon assay (Huh-7.5 cells with subgenomic replicon)
- **Readout:** Replicon RNA reduction at 72 h
